# Contributing to chastler

Thank you for your interest in contributing to chastler! Please follow these guidelines to ensure a smooth contribution process:

1. **Fork the Repository**: Create a personal copy of the repository on your GitHub account.
2. **Clone the Forked Repository**: Use the command `git clone <your-fork-url>` to clone your fork locally.
3. **Create a New Branch**: Use `git checkout -b <feature-branch-name>` to create a new branch for your feature or bug fix.
4. **Make Your Changes**: Implement your changes and ensure they adhere to the project's coding standards.
5. **Test Your Changes**: Run existing tests and add new tests if necessary to verify your changes work as expected.
6. **Commit Your Changes**: Use `git commit -m "Brief description of changes"` to commit your changes with a clear message.
7. **Push Your Branch**: Push your changes to your fork using `git push origin <feature-branch-name>`.
8. **Submit a Pull Request**: Go to the original repository on GitHub and create a pull request from your branch.

We appreciate your contributions and look forward to collaborating with you! More information is forthcoming. Thank you.
